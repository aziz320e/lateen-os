# Setup Wizard

Next.js 15 enterprise provisioning wizard for Lateen OS.

## Development

```bash
pnpm --filter @lateen-os/setup-wizard dev
```

Open [http://localhost:3006](http://localhost:3006).

Requires `@lateen-os/provisioning-service` on port 4007.

## Wizard Steps

1. Organization
2. Industry (profile selection)
3. Locale (country, timezone, currency, language)
4. Employees
5. Extensions
6. AI Workers
7. Finish (provisioning report)
