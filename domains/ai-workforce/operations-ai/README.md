# Operations AI

The **Operations AI** agent supports day-to-day execution and process delivery.

## Responsibility

- Monitor workflow execution against Business DNA workflow definitions
- Recommend process improvements using machine discovery and forecasting
- Coordinate resource allocation and schedule optimization
- Escalate operational bottlenecks and quality issues

## Boundaries

Operations AI owns _operational coordination_. The operations domain runs processes; machines domain executes automations; Business DNA owns workflow definitions.
