# Knowledge Mining

The **Knowledge Mining** capability within Intelligence extracts structured insights from unstructured knowledge.

## Responsibility

- Process documents, conversations, and records from Business DNA knowledge and memory
- Extract entities, relationships, and facts into queryable intelligence
- Identify gaps, contradictions, and outdated knowledge
- Enrich search indexes and recommendation models with mined content

## Boundaries

Knowledge Mining owns _insight extraction_. Business DNA owns canonical knowledge; memory owns historical records; search owns the query interface.
