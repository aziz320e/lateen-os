# Machines

The **Machines** domain manages automation, integrations, and system orchestration within Lateen OS.

## Responsibility

- Define and operate automated workflows, bots, and scheduled jobs
- Manage integrations with external tools, APIs, and data sources
- Monitor system health, uptime, and execution reliability
- Govern the registry of active machines and their configurations

## Boundaries

This domain owns _how systems run automatically_. It does not own business rules (other domains define those), AI agents (ai-workforce), or infrastructure provisioning (infrastructure/).
