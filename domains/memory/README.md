# Institutional Memory

The **Institutional Memory** domain (`memory/`) manages organizational knowledge, history, and persistent context.

## Responsibility

- Store and retrieve institutional knowledge, decisions, and records
- Maintain a searchable history of events, conversations, and outcomes
- Provide context to AI agents and human operators across domains
- Serve as a primary monitoring input for Proactive AI agents
- Govern data retention, indexing, and knowledge lifecycle policies

## Boundaries

This domain owns _what the organization remembers_. It does not own AI agents (ai-workforce), the canonical business model (business-dna), or the systems that produce events (machines, operations).
