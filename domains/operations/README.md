# Operations

The **Operations** domain manages the day-to-day execution of organizational work.

## Responsibility

- Define and run core business processes and workflows
- Coordinate resources, schedules, and task delivery
- Monitor operational efficiency, quality, and throughput
- Ensure consistent execution across teams and functions

## Boundaries

This domain owns _how work gets done_. It does not own strategic identity (business-dna), financial reporting (finance), or initiative planning (projects).
