# Projects

The **Projects** domain manages time-bound initiatives and their delivery.

## Responsibility

- Define project scope, milestones, and deliverables
- Track progress, dependencies, and resource allocation
- Manage project timelines, risks, and status reporting
- Coordinate cross-domain work under a unified initiative

## Boundaries

This domain owns _how initiatives are planned and delivered_. It does not own ongoing operational processes (operations), product roadmaps (products), or financial budgets (finance).
