# العربية

## سياسة الأصول

هذا المجلد مخصص للأصول الثنائية التي لا يمكن التعبير عنها كنص — لقطات شاشة، شعارات، صور مصدَّرة بدقة عالية من رسوم Mermaid عند الحاجة لاستخدامها خارج Markdown (مثل عرض تقديمي). حتى تاريخ هذا الإصدار، **كل** الرسوم البيانية في الكتيّب مُعبَّر عنها كنص Mermaid مضمّن داخل `docs/handbook/*.md` (انظر [فهرس الرسوم البيانية](../diagrams/README.md))، لذا لا توجد أصول ثنائية مطلوبة بعد. يبقى هذا المجلد فارغًا عن قصد إلى حين وجود حاجة فعلية — لا صور نائبة (placeholder images) تُضاف مسبقًا.

# English

## Assets Policy

This directory is reserved for binary assets that cannot be expressed as text — screenshots, logos, or high-resolution exports of Mermaid diagrams when needed outside Markdown (e.g. a slide deck). As of this release, **every** diagram in the handbook is expressed as inline Mermaid text inside `docs/handbook/*.md` (see the [diagram index](../diagrams/README.md)), so no binary assets are required yet. This directory stays intentionally empty until there is an actual need — no placeholder images are added in advance.
