# Microsoft Teams Connector

Integration provider extension for **Microsoft Teams** (microsoft-teams).

## Install

```bash
lateen marketplace install teams-connector
lateen extensions install extensions/teams
```

## Capabilities

- messages
- meetings

## Auth Methods

- OAUTH2
