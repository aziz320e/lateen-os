# Microsoft 365 Connector

Integration provider extension for **Microsoft 365** (microsoft-365).

## Install

```bash
lateen marketplace install microsoft-365-connector
lateen extensions install extensions/microsoft-365
```

## Capabilities

- email
- calendar
- storage

## Auth Methods

- OAUTH2
- OIDC
