# Gmail Connector

Integration provider extension for **Gmail** (gmail).

## Install

```bash
lateen marketplace install gmail-connector
lateen extensions install extensions/gmail
```

## Capabilities

- email
- send
- labels

## Auth Methods

- OAUTH2
