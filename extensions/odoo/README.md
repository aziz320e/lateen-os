# Odoo Connector

Integration provider extension for **Odoo** (odoo).

## Install

```bash
lateen marketplace install odoo-connector
lateen extensions install extensions/odoo
```

## Capabilities

- orders
- inventory
- accounting

## Auth Methods

- API_KEY
- BASIC_AUTH
