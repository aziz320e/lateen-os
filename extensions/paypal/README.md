# PayPal Connector

Integration provider extension for **PayPal** (paypal).

## Install

```bash
lateen marketplace install paypal-connector
lateen extensions install extensions/paypal
```

## Capabilities

- payments
- payouts

## Auth Methods

- OAUTH2
- API_KEY
