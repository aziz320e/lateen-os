# Shopify Connector

Integration provider extension for **Shopify** (shopify).

## Install

```bash
lateen marketplace install shopify-connector
lateen extensions install extensions/shopify
```

## Capabilities

- orders
- products
- customers

## Auth Methods

- OAUTH2
- API_KEY
