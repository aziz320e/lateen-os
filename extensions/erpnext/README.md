# ERPNext Connector

Integration provider extension for **ERPNext** (erpnext).

## Install

```bash
lateen marketplace install erpnext-connector
lateen extensions install extensions/erpnext
```

## Capabilities

- items
- orders
- invoices

## Auth Methods

- API_KEY
- BEARER_TOKEN
