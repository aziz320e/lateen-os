# Dropbox Connector

Integration provider extension for **Dropbox** (dropbox).

## Install

```bash
lateen marketplace install dropbox-connector
lateen extensions install extensions/dropbox
```

## Capabilities

- files
- sync

## Auth Methods

- OAUTH2
- API_KEY
