# QuickBooks Connector

Integration provider extension for **QuickBooks** (quickbooks).

## Install

```bash
lateen marketplace install quickbooks-connector
lateen extensions install extensions/quickbooks
```

## Capabilities

- invoices
- accounts
- customers

## Auth Methods

- OAUTH2
