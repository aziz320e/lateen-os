# Google Drive Connector

Integration provider extension for **Google Drive** (google-drive).

## Install

```bash
lateen marketplace install google-drive-connector
lateen extensions install extensions/google-drive
```

## Capabilities

- files
- upload
- download

## Auth Methods

- OAUTH2
