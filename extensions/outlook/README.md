# Outlook Connector

Integration provider extension for **Outlook** (outlook).

## Install

```bash
lateen marketplace install outlook-connector
lateen extensions install extensions/outlook
```

## Capabilities

- email
- send

## Auth Methods

- OAUTH2
- OIDC
