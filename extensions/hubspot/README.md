# HubSpot Connector

Integration provider extension for **HubSpot** (hubspot).

## Install

```bash
lateen marketplace install hubspot-connector
lateen extensions install extensions/hubspot
```

## Capabilities

- contacts
- deals
- companies

## Auth Methods

- OAUTH2
- API_KEY
