# Google Workspace Connector

Integration provider extension for **Google Workspace** (google-workspace).

## Install

```bash
lateen marketplace install google-workspace-connector
lateen extensions install extensions/google-workspace
```

## Capabilities

- email
- calendar
- contacts

## Auth Methods

- OAUTH2
- OIDC
