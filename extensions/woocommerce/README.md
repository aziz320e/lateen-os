# WooCommerce Connector

Integration provider extension for **WooCommerce** (woocommerce).

## Install

```bash
lateen marketplace install woocommerce-connector
lateen extensions install extensions/woocommerce
```

## Capabilities

- orders
- products

## Auth Methods

- API_KEY
- BASIC_AUTH
