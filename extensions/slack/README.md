# Slack Connector

Integration provider extension for **Slack** (slack).

## Install

```bash
lateen marketplace install slack-connector
lateen extensions install extensions/slack
```

## Capabilities

- messages
- channels

## Auth Methods

- OAUTH2
- BEARER_TOKEN
