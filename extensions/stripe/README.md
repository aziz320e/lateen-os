# Stripe Connector

Integration provider extension for **Stripe** (stripe).

## Install

```bash
lateen marketplace install stripe-connector
lateen extensions install extensions/stripe
```

## Capabilities

- payments
- subscriptions
- webhooks

## Auth Methods

- API_KEY
- WEBHOOK_SECRET
