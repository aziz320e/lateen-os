# OneDrive Connector

Integration provider extension for **OneDrive** (onedrive).

## Install

```bash
lateen marketplace install onedrive-connector
lateen extensions install extensions/onedrive
```

## Capabilities

- files
- upload

## Auth Methods

- OAUTH2
