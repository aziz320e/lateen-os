# WhatsApp Business Connector

Integration provider extension for **WhatsApp Business** (whatsapp-business).

## Install

```bash
lateen marketplace install whatsapp-business-connector
lateen extensions install extensions/whatsapp-business
```

## Capabilities

- messages
- templates

## Auth Methods

- BEARER_TOKEN
- WEBHOOK_SECRET
